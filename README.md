## PennyPack - 티끌모아, 여행
**교환학생 생활, PennyPack과 함께 시작해요!**

PennyPack은 한국인 교환학생을 위해 특별히 디자인된 앱입니다. 마트의 상품 가격표를 카메라로 스캔하면, 자동으로 환율을 적용한 원화 가격을 계산해줍니다. 동시에, 상품명을 한국어로 번역하여 언어 장벽 없이 쇼핑을 도와드립니다. 준비된 체크리스트로 계획적인 쇼핑을 즐겨보세요.

### 📌 Features
- **쇼핑 리스트**: 쇼핑을 계획하고 실시간으로 관리할 수 있는 쇼핑 리스트를 작성하고 빠짐없이 체크할 수 있습니다.
- **상품 스캔**: 카메라를 사용해 가격표를 스캔하면 상품명과 가격을 자동으로 인식하여, 번역과 원화 계산을 동시에 보여줍니다.
- **총액 계산**: 카트에 담긴 상품들의 총 금액을 계산하여 예산 초과 없이 효율적으로 쇼핑하세요.
- **월별 지출**: 캘린더로 달마다 지출한 내역의 영수증을 확인하여, 경제적이고 효율적인 예산 관리가 가능합니다.
